# Josefina Iriarte — Web

Primera versión de la web de Josefina Iriarte, enfocada en extranjería e inmigración.

Stack: Astro + CSS propio. Despliegue inicial previsto en Vercel y posterior integración con Cloudflare.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

El contenido jurídico deberá ser revisado y aprobado por el despacho antes de la publicación definitiva.
